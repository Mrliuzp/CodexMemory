## 待 Terra 核实并收口的契约差异

### 1. 上传错误的 HTTP 状态映射

冻结契约要求：

- 非法扩展名、非法编码、语法错误和非对象根节点：HTTP 400，`contract_invalid_file`。
- 相同 `method + path` 改变 `operationId`：HTTP 409，`contract_operation_id_conflict`。
- 文件超过 2 MiB：HTTP 413，`contract_file_too_large`。
- 规范校验、Profile、不支持版本、缺失或重复 `operationId`：HTTP 422，并返回各自固定的 `contract_*` 错误码。

当前实现需要按上述分类复核，不能将所有 OpenAPI 错误统一映射为 HTTP 422。每类必须有 API 层回归断言。

### 2. 数据模型字段与冻结规格对齐

冻结规格使用：

- `contract_revisions.markdown_document`
- `api_operations.tags`
- `api_operations.deprecated`

当前实现仍需复核是否使用 `markdown`、`tags_json` 且缺少 `deprecated`。V1.5 尚未发布迁移，可以直接修订 `0023_v15_openapi_revisions`，不要为此新增 `0024`。修复应贯通迁移、SQLAlchemy 模型、Repository、API、确定性 Markdown、管理端展示和测试。

### 3. V1.5 跨项目错误契约

V1.5 管理 API 的跨项目读取或写入必须返回 HTTP 403 和 `permission_denied`，不能对外暴露 `project_access_denied`。建议只调整 V1.5 endpoint/helper，避免改变其他版本已有 API 行为，并补跨项目读写回归。
