# V1.2 领域边界

| 边界 | 负责内容 | 不负责内容 |
| --- | --- | --- |
| 管理后台 | 导航、表格渲染、URL 查询状态、令牌输入 | 授权决策、数据写入 |
| 管理 API | 身份认证、项目/作用域检查、分页、脱敏、只读 DTO | 导入、发布、重试、回放 |
| 查询服务 | 原始记录、候选记忆、记忆、任务、Outbox、检索和审计数据的读模型 | 修改 V1.1 聚合数据 |
| 作用域投影 | `knowledge_scopes` 和面向历史项目数据的逻辑 `default` 投影 | 重写历史记录 |
| V1.1 运行时 | Append、处理、检索、发布和 Worker 行为 | 管理后台展示 |

P0 只允许 `GET` 接口。写入流程明确推迟到 P1，并且必须拥有独立权限、审计记录、幂等控制和功能开关。
